# إعداد Google Sheets للكتالوج — ZV-EG

## مصدر البيانات
يرتبط الكتالوج بورقة Google Sheets المنشورة للقراءة فقط بصيغة CSV. لا يحتاج الموقع إلى Google API key أو أي كلمة مرور. رابط التحرير لا يُستخدم داخل كود الموقع؛ الكود يقرأ رابط النشر العام فقط.

## الأعمدة المطلوبة
يجب الحفاظ على الأعمدة التالية حرفياً:
- \`id\` (فريد ولا يتكرر)
- \`name_ar\`
- \`brand\`
- \`category\`
- \`variant\`
- \`price\`
- \`old_price\`
- \`currency\`
- \`status\`
- \`availability\`
- \`image\`
- \`product_url\`
- \`source_url\`
- \`source_checked_at\`
- \`source_note\`
- \`description\`
- \`image_credit\`

## قواعد التحقق قبل النشر
- الأسعار أرقام موجبة بالجنيه المصري ومن دون فواصل آلاف.
- \`source_checked_at\` بصيغة \`YYYY-MM-DD\`.
- \`status\`: \`in\` أو \`limited\` أو \`out\` أو \`unknown\` أو \`check\`.
- كل صف يجب أن يحتوي على المعرّف والاسم والعلامة التجارية والفئة والنسخة والسعر ورابط مصدر HTTPS وتاريخ التحقق.
- يجب ألا تقل الورقة عن 130 صف منتج في الوقت الحالي؛ هذا حاجز أمان يمنع نشر ملف فارغ أو جزئي. يُراجع هذا الحد عند توسيع الكتالوج أو تقليصه عمداً.
- لا تخلط نسخاً أو سعات مختلفة في نفس الصف، ولا تعتبر توفر المنتج مؤكداً لمجرد وجود سعر.

## المزامنة
1. عدّل الصفوف في Google Sheets.
2. GitHub Actions يقرأ الورقة المنشورة تلقائياً كل 3 ساعات، وكذلك بعد تغيير سكربت المزامنة أو تشغيله يدوياً.
3. يتم التحقق من بنية CSV، الأعمدة، عدد الصفوف، عدم تكرار المعرّفات، الأسعار والتواريخ والروابط.
4. إذا نجحت كل الاختبارات وتغيرت البيانات، يتم تحديث \`data/products.json\` بعملية ذرية، ثم ينشأ commit تلقائي.
5. كل commit للكتالوج يشغّل نشر GitHub Pages. إذا فشل التحميل أو أي تحقق، تبقى آخر نسخة سليمة كما هي.

## حدود الصلاحيات والأمان
- رابط CSV المنشور عام للقراءة فقط؛ لا تضع بيانات خاصة في الورقة المنشورة.
- رابط التحرير لا يمنح الموقع حق الكتابة إلى الشيت.
- لوحة الإدارة تحتفظ بالمسودات داخل المتصفح وتتيح استيراد/تصدير CSV وJSON، لكنها لا تكتب مباشرة إلى Google Sheets أو GitHub.
- لا تضع GitHub token أو Google API credentials في HTML أو JavaScript عام. أي كتابة من لوحة الإدارة تحتاج Backend موثوقاً ومصادقة منفصلة.


### الحفاظ على الصور الموثقة
لو خانة `image` أو `image_credit` فاضية في Google Sheets، المزامنة هتحافظ على القيمة الموثقة الموجودة بالفعل في الكتالوج بدل ما تمسحها. لتحديث صورة، ضع رابط HTTPS جديدًا في خانة `image`. الخانة الفارغة لا تُستخدم لمسح صورة موجودة بالخطأ.
