# ZV-EG — SouqScan | منصة مقارنة أسعار المنتجات

منصة عربية RTL لكتالوج منتجات Vodafone Egypt ومقارنة لقطات الأسعار المتاحة من مصادر سوقية. المشروع مستقل وغير تابع أو معتمد رسمياً من Vodafone Egypt.

## الحالة التشغيلية

- الموقع مبني على GitHub Pages من المجلد `vodafone-egypt-catalog/`.
- كتالوج المنتجات الحالي قاعدة أولية قابلة للمراجعة، وليس حصرًا نهائياً لكل منتجات Vodafone أو السوق المصري.
- توجد مهمة GitHub Actions لمحاولة مزامنة عروض المنافسين كل 3 ساعات باستخدام PriceLens Partner API. الجدولة تعني محاولة التحديث؛ نجاح كل تشغيل واكتمال التغطية يتحددان من سجل Actions وحقول `price-provider.json`.
- لا توجد تغذية مباشرة معتمدة من Vodafone Egypt داخل المشروع؛ أسعار Vodafone هي لقطات محفوظة مع تاريخ ورابط مصدر.
- الأسعار ليست بثاً لحظياً. تحقق من السعر النهائي والضريبة والشحن والمخزون والضمان مع البائع قبل الشراء.

## الملفات الأساسية

- `index.html`: واجهة SouqScan العامة.
- `app.js` و`styles.css`: الكتالوج والبحث والفلاتر والتجميع حسب النوع والماركة.
- `data/products.json`: كتالوج المنتجات وأسعار Vodafone المرجعية.
- `data/market-comparisons.json` و`data/market.json`: لقطات مقارنة بحثية محفوظة.
- `data/price-provider.json`: آخر نتائج مزامنة PriceLens.
- `data/price-provider-map.json`: ربط منتجات الكتالوج بمعرفات المزود.
- `data/price-history.json`: تاريخ الأسعار الأسبوعي واليومي.
- `admin.html`: أداة مراجعة وتصدير واستيراد لمسودات محلية؛ لا تنشر التعديلات مباشرة إلى الإنتاج.

## مزامنة المنافسين

الملف `.github/workflows/price-sync.yml` يحاول التحديث كل ثلاث ساعات، ويتطلب GitHub Actions Secret باسم `PRICELENS_API_KEY`. يبقى المفتاح داخل Secrets ويُستخدم من الخادم فقط؛ لا تضعه داخل الواجهة أو ملفات المستودع ولا ترسله في المحادثة.

السكربت يقتصر على المتاجر المحددة في قائمة السماح، ويشترط تطابقاً واضحاً للعلامة والموديل والسعة/الذاكرة، ويتحقق من حداثة العرض والعملة ورابط المصدر. يعيد محاولة أخطاء الشبكة والخوادم المؤقتة لعدد محدود من المرات. لا يوقف الدفعة بسبب فشل منتج واحد؛ يحتفظ بآخر لقطة لذلك المنتج ويتابع المنتجات التالية. عند بلوغ حد API يحفظ التحديثات الناجحة فقط ويسجل التغطية والأخطاء وموضع الاستكمال للتشغيل التالي.

راجع شروط PriceLens وخطة API وحقوق عرض البيانات العامة والتغطية الفعلية لمصر قبل اعتبار الخدمة أساساً تجارياً أو وعداً بتغطية كل المنتجات. لا يحدث السكربت أسعار Vodafone Egypt من تلقاء نفسه.

## Google Sheets ولوحة الإدارة

Google Sheets مصدر استيراد ومزامنة بيانات المنتجات عبر CSV منشور. مهمة `google-sheets-sync.yml` تتحقق من البيانات قبل استبدال `products.json`. التعديلات لا تُنشر إلا بعد نجاح التحقق والتزام التحديث ونشر Pages.

لوحة `admin.html` أداة تدقيق واستيراد وتصدير للمسودات المحلية في هذا المتصفح فقط. لا تكتب مباشرة إلى Google Sheets أو المستودع ولا تمثل نظام صلاحيات أو لوحة نشر مشتركة. لم يتم إنشاء Backend آمن للكتابة من المتصفح.

## مطابقة الأسعار وجودة البيانات

لا تقارن إلا نفس الموديل والنسخة قدر الإمكان. افصل بين السعة والرام والشبكة واللون والنسخة الإقليمية، وبين الجديد والمستعمل والمجدد، والبائع والضمان المحلي والدولي، والسعر المتاح والسعر المرصود لمنتج نفد مخزونه. العروض غير المتطابقة لا تدخل في حساب أقل سعر أو التوفير.

نقص الصور أو الروابط يظل معلناً؛ لا تربط صورة أو سعراً أو مطابقة غير مؤكدة لمجرد ملء الفراغ.

## سجل الأسعار والتوقعات

التوقع قصير الأجل لا يعمل تلقائياً لمجرد وجود تاريخ أسبوعي. يتطلب سجل 90 قراءة يومية لنفس SKU والمتجر وفق المنهج الحالي، ثم اختباراً زمنياً خارج العينة ومقارنة بخط أساس. لا تعرض احتمالات رقمية أو توصية «اشترِ الآن/انتظر» قبل إثبات أداء النموذج ومعايرته.

## التشغيل والاختبارات

من داخل مجلد المشروع:

```bash
python3 -m http.server 3000
node --check app.js
node --check analytics.js
node --check scripts/sync-prices.mjs
node --check scripts/validate-data.mjs
node scripts/sync-prices.mjs --self-test
node scripts/validate-data.mjs
```

لا تحفظ مفاتيح API في HTML أو JavaScript أو ملفات البيانات. كل تعديل يمر عبر فرع وPull Request وفحوص Actions. نجاح نشر GitHub Pages لا يثبت وحده جودة البيانات أو اكتمال المزامنة؛ افحص النشر والمزامنة كلًّا على حدة.
